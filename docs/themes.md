# Theme gallery

Every theme in [`src/themes.json`](../src/themes.json) — **166 themes** — previewed live below.

These preview images render **live** from the hosted demo instance (`https://github-readme-leetcode-stats.vercel.app`) with every section turned on (`sections=profile,solved,streak,skills,languages,heatmap`), so what you see here is exactly what that theme looks like right now against real data — not a static, possibly-stale screenshot.

**Self-hosting your own instance?** Every image/link below points at the demo domain — `https://github-readme-leetcode-stats.vercel.app`. Swap that for your own deployment's domain (e.g. `https://your-app.vercel.app/api/card?theme=<name>`) and the rest of the URL works unchanged. Drop or reorder `sections=` to match whichever sections you actually use — it doesn't have to be all six.

Pick a theme name from the table below, then pass it as `?theme=<name>` on your own card URL. See the [main README](../README.md#options) for the full list of query params.
